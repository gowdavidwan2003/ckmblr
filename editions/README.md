One folder per edition.

    editions/2026-09-24/        daily
      today/                    the full daily post: rates + news + export
        work/                   edited copies of the card HTML
        out/                    built PNGs — these are what get posted
      market/                   market close cards (same work/ + out/)
      news/                     news-only cards (same work/ + out/)
    editions/2026-09/           monthly

Build from inside the set's folder, e.g. `cd editions/2026-09-24/today`.
